Программа обмена данными между "ОИК Диспетчер" и сторонними СУБД

Использование:
Iface.Oik.DB-bredge сервер_тм компьютер_оик /pпериод_запуска /dтип,сервер,база,пользователь,пароль

период_запуска - периодичность исполнения в секундах, можно указать исполнение чуть раньше.
Например /p60-1 запуск каждую минуту за секунду до наступления времени.
умолчание 10 секунд

тип - MS, MY, PG. Microsoft SQL, mySQL, PostgreSQL соответственно

Дополнительные параметры
/fфайл_с_запросом_на_сервере_ОИК
/uпользователь_ОИК
/sпароль_ОИК


Файл с запросами хранится на сервере ОИК. Запросов в файле может быть несколько, разделённых точкой с запятой.
Текст запроса сначала обрабатывается препроцессором, который исполняет текст между знаками % с помощью сервера ОИК.
Таким образом можно исполнить выражения на языке ЯРД, допустимые в поле "выражение" телепараметров.

Для занесения информации в ОИК исполняется запрос SELECT, который должен вернуть таблицу из пяти колонок:
Тип, Канал, КП, Объект, Значение

Где тип #TC или #TT для ТС и ТИТ соответственно

Пример
<<
SELECT * from ImportTable;

INSERT INTO ExportTable ( D, val1, val2, val3, val4 )
  SELECT NOW, %#TT0:2:1{}%, %#TT0:2:2{}%, %#TT0:2:3{}%, %#TT0:2:4{}%;
>>
